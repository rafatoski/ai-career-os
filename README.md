# Learning Companion

Learning Companion es mi espacio personal de estudio para seguir, paso a paso, una ruta de aprendizaje enfocada en convertirme en AI Product Engineer.

La aplicación organiza mis módulos y lecciones, reproduce los cursos de YouTube, recuerda exactamente dónde dejé cada video y reúne en un mismo lugar lecturas, notas, ejercicios, quizzes, flashcards y proyectos prácticos.

Todo el progreso se guarda localmente. No es un LMS, una plataforma colaborativa ni una aplicación de productividad: es una experiencia tranquila y enfocada que me ayuda a saber qué debo estudiar a continuación y continuar cada día sin perder el contexto.
